## 🔴 最優先: App Store プライバシーラベルの入力再開

**中断箇所**: 「おおよその場所」のトラッキング設問(はい/いいえの選択画面)でスクロール中に中断。**まだ何も保存・確定していない**(キャンセル可能な状態)。

### 再開手順

App Store Connect → まとめくん → 配信 → アプリのプライバシー → データタイプ「編集」から再度データ収集フローに入り、以下を上から順に回答する。

#### 1. おおよその場所(位置情報)
- ✅ 追加済み(チェック済み)
- ✅ 目的: サードパーティ広告(選択済み)
- ✅ 個人情報に関連付けられるか: **いいえ**(選択済み)
- ⬜ **トラッキングに使用するか: はい**(ここで中断。AdMob 広告のため「はい」)

#### 2. デバイス ID(識別子)
- ✅ 追加済み(チェック済み)
- ⬜ 目的: **サードパーティ広告** + **アプリ機能**(devicehash はコメント機能にも使うため両方)
- ⬜ 個人情報に関連付けられるか: **いいえ**
- ⬜ トラッキングに使用するか: **はい**

#### 3. 既存項目(製品の操作・その他の使用状況データ・パフォーマンスデータ)
- 変更不要。そのままアナリティクス目的・トラッキングなしで維持

#### 4. 最終確認 → 公開
- 全項目の回答をプレビュー画面で確認
- 「公開」をクリックして確定

> ⚠️ **注意**: この画面はブラウザの手動操作で 1 問ずつ丁寧に進める必要がある(自動化中に迷子になりやすい UI のため)。短いステップに区切って進めることを推奨。
