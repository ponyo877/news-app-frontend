## 2. GROWTH-PLAN の前提のうち、事実と違っていたもの

### ❌「読み上げは競合に存在しない」→ 存在する

**2ch/5chまとめ 読み上げ+（RANRANソリューションズ、2026/06/17 更新）** が正面から競合する。
音声読み上げ、**読み上げ連動の自動スクロール**、再生速度と声の高さの調整、ブックマーク、
サイトの表示/非表示、**RSS登録によるサイト自由追加**まで揃っている。

ただし規模は 500+ DL・レビュー数が付かない水準で、対応サイトは 11件。
正確には「読み上げは競合にない」ではなく **「読み上げで競合しているのは実質1本だけで、それも小規模」**。
訴求に使うのは有効だが、「唯一」「初」とは書けない。

### ❌「69サイト横断が差別化になる」→ ならない。むしろ劣位

評価1位（4.8・10万DL）の lifeofsnufkin は **掲載サイト100以上**を明記している。
サイト数で勝負すると負ける。「69サイト」は網羅性の訴求としては使えるが、**優位性としては使えない**。

### ✅「話題検知」は確認した範囲でどこにもない

複数サイトが同じスレをまとめたことを検知する機能は、調べた11本のいずれにも無い。
**現時点で唯一、まとめくんにしかない機能。** ASO の一番手はここに置くべき。

## 3. レビューで繰り返されている不満（実データ）

### ① Cookie 同意ポップアップ ← 最多。しかも複数アプリで独立に発生

- Marimba（1★・2022/11）「アプデしてから、Cookieの承諾を要求するバナーが下部に表示されるようになってしまった。
  閉じるボタンが反応しないため2/3の画面で閲覧するしかなくなり不便になった。**使いづらいため他のアプリに移行する**」
- Marimba（1★）「Cookie使用の確認が下部に表示されるが、閉じるを押しても画面下部をタップでスクロールが優先して
  反応する為、閉じるが機能せず消せない。**使い物にならないんでアンインストールします**」
- lifeofsnufkin（2025/05）「『ライブドアブログでは広告のパーソナライズや効果測定のためクッキーを使用しています』
  というポップアップが頻繁に出てくるので、これが無ければと思っています」

**まとめくんは構造的にこれを踏まない。** `src/scraper/applyRules.ts` の `COMMON_REMOVE_SELECTORS` が
全サイトで `script` / `noscript` を除去してから WebView に渡すため、
元サイトの Cookie 同意バナーはそもそも実行されない（コード確認済み）。

### ② 画像が出ない・レイアウトが崩れる

- Marimba（1★・43人が「役立った」）「画像が見れない。**画像が見れないとスレの内容が全く掴めない**」
- lifeofsnufkin「動画や画像のレイアウトが右側の border をはみ出すように崩れてる」

**まとめくんは画像を消していない。** `defaultRules.json` で除去している `img` は
1サイトの固定バナー（`img[src*="/parts/ichiosi.png"]`）1件だけで、他はすべて `script` 要素（確認済み）。

### ③ 読み込み完了でスクロール位置が先頭に戻る

- lifeofsnufkin（2026/02）「読み込んでる間にどんどん読み進めていたのに、読み込み完了すると
  突然ページの1番上までスクロールが戻される。**このまま改善されなければ別のアプリに移行します**」

まとめくんは整形済みの HTML を一度だけ描画する設計なので構造的には起きないはずだが、
**実機で未確認。ストア文言に書く前に確かめること。**

### ④ 誤タップを誘う広告

- Marimba（1★・2026/07）「◯トリの広告が無駄に開いてしまい記事が読めない」

**切り返さない。** 自社も AdMob で収益化しているため（GROWTH-PLAN 5-1 の指示どおり）。
ただし裏を返せば「画面下部にタップ要素を置かない」という 1.44 以降の設計判断は正しい。

### ⑤ サイト管理の導線が悪い

- lifeofsnufkin「記事内に『このサイトをお気に入り登録/非表示』ボタンを用意してほしい。
  記事を見て非表示にしたいサイトを見つけた場合、**サイト一覧タブに移動してサイト名を探すのが苦行**」
- Marimba（1★）「サイトの追加が何故か URL 直打ちでしか出来ないし追加後にサイト名が表示されない。
  **登録したお気に入りサイトは全て消えているという不具合**まで発生し、アンインストールした」

**まとめくんにも記事画面からサイトを非表示にする導線は無い。** これは切り返しではなく**実装の宿題**。
記事ヘッダーのメニューに「このサイトを非表示」を足すだけで、実測で需要が確認できている改善になる。

### ⑥ クラッシュ・端末互換

- lifeofsnufkin（2025/05）「**機種変更をしたところ、今まで使っていたアプリが頻繁にクラッシュするようになったので、
  こちらのアプリに乗り換えました**」← 乗り換えは実際に起きている。受け皿になれる
- Marimba「Pixel4a の全画面表示だとタスクバーが重なりアプリそのものを使えない」「タッチ精度がおかしい、クラッシュ」

## 4. 説明文に入れる切り返し

競合を名指しせず、**自分の性質として書く**。「◯◯が無い」ではなく「◯◯になる」と書く。

| 不満 | 説明文に入れる文言 | 裏付け |
|---|---|---|
| ① Cookie ポップアップ | **「記事は端末の中で組み立て直して表示します。元サイトのスクリプトを動かさないので、Cookie同意の確認や、あとから重なってくる表示に読書を邪魔されません。」** | コード確認済 |
| ② 画像が出ない | **「画像もGIFもそのまま表示します。スレの流れが画像で成り立っている記事も、そのまま読めます。」** | コード確認済 |
| ③ スクロールが戻る | 「整形が終わってから表示するので、読んでいる途中で先頭に戻されることがありません。」 | **実機確認後に採用** |
| ⑤ サイト管理 | （実装後に）「読んでいる記事から、そのサイトをそのまま非表示にできます。」 | **未実装** |
| ⑥ 乗り換え | 「お気に入りと履歴は端末に保存します。ログインは不要です。」（消失不安への回答） | 実装済 |

**「広告」の語は一切使わない。** ①②③は結果として広告の話に触れずに同じ利益を伝えられる。
これが今回の調査でいちばん価値のある発見で、AdMob 違反を再発させずに競合の最大の弱点を突ける。

## 5. ASO で併せて直すもの

- **カテゴリ**: 自社は「ニュース＆雑誌」。1位の lifeofsnufkin は「書籍＆参考書」、
  Marimba と読み上げ+ は「エンタメ」。**まとめ系の主戦場はニュース＆雑誌ではない。**
  競合が少ない枠を選んでいる可能性があり、変更を検討する価値がある
- **検索順位**: 「2chまとめ」の検索結果にまとめくんは**1件も出てこない**。
  レビュー0件・50DLでは順位が付かないため、まずレビュー獲得（`expo-store-review` 導入済み）が先
- **キーワード**: 1位アプリは説明文の後半を丸ごとキーワード列挙に使っている
  （なんJ／VIP／鬼女／気団／SSまとめ／オカルト／専ブラ／あんてな 等）。
  露骨だが機能している。まとめくんの説明文は読み物として整いすぎていて、検索語の網羅が足りない
