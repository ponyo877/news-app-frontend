## 決定事項

- **実機映像のみ**。生成 AI に画面も文字も描かせない(スクショと同じ方針)。App Store 版は端末フレーム・手・バッジ・URL・価格・時節ネタを入れない
- 主役は「読まずに、聴く。」(読み上げ + 追従ハイライト)。ストアのプロモーションテキストと同じ訴求
- 音は BGM + 効果音のみ(ナレーション・読み上げの実録なし。実録は `promo/README.md` §6 に手順だけ残した)
- scenario.com は使っていない(装飾はスクショ v2 の透過 PNG を流用)
- 「広告なし/広告カット」「唯一/初」「具体的なサイト数」「今すぐダウンロード」等の CTA は書かない
- 撮影用ビルドは `EXPO_PUBLIC_ADS_ENV=off`(`src/lib/ads.ts` の `adsHidden`)で広告枠と UMP/ATT を消す。ストアビルドには影響しない

## ストーリーボード(1 テイク連続撮影・30fps)

| # | 実機の操作 | テロップ | 速度 |
|---|---|---|---|
| S1 | ランキング(日間)を軽くスクロール → 1 位をタップ | 今日いちばん読まれたスレを、 | 1.5× |
| S2 | 記事 → ⋮ → 読み上げ → バー出現・タイトルが光る → [ジャンプ] 2.0x で本文をハイライトが進み画面が追従 | 読まずに、聴く。→ 読んでいる行を追従ハイライト | 1.0× |
| S3 | ✕ → 戻る → ホーム → 🔥 → 「いま祭りのスレ」 | 盛り上がってるスレが、わかる。 | 1.5× |
| S4 | 祭りの 1 件目 → 本文をスクロール | 本文だけが、すっと出る。 | 1.25× |

Social 版は前にフック「通勤中、スレ読む時間ない。」(1.5 秒)、後ろにエンドカード(アイコン・まとめくん・App Store / Google Play の文字ピル)。
ポスターフレーム = 読み上げのハイライトが本文へ移った直後(`npx tsx scripts/poster.ts --take m2` の `poster=`)。

撮影日(2026-08-29)の実画面: 日間 1 位は NG ワード(容疑者・胸・デカすぎる)で間引いた結果の「鬼滅の刃の鬼殺隊で一番強いキャラ」、祭りは「同志社国際高の沖縄研修旅行」(6 サイト)。

## 撮影で分かったこと(次回のために)

- `simctl recordVideo` の時間軸は壁時計より**前にも後ろにも**ずれる(m1: +1 秒、m2: −4 秒)。時刻窓での同期は破綻するので、画面変化の**順序**で 9 つの基準点を対応づける(`promo/capture/sim/postprocess.ts`)
- 読み上げのタイトルは長く、速度を切り替えるたびに先頭から読み直すので、本文のハイライトが進むのは開始 7 秒前後から。S2 は「タイトル 4 秒 → 本文 7.7 秒」の 2 パート
- 祭り一覧を Maestro で swipe すると離し際がタップになって記事が開く。一覧は静止で撮る
- ⋮ メニュー(RN Modal)は Maestro から 1 要素に潰れて見える。文言は `.*読み上げ.*` で待ち、項目は座標で押す
- 通知プレ許諾は既読 3 本で一覧に戻った瞬間に出る。撮影前に `prep-notify.yaml` で「あとで」を押しておく

## 規定(確認済み)

- App Store プレビュー: 886×1920・15〜30 秒・30fps・H.264 High 4.0(10〜12Mbps)・ステレオ AAC 256k 48kHz か無音・最大 3 本/言語・実機映像のみ・テロップと単純なトランジションは可
- Play プロモ動画: YouTube URL(公開か限定公開・収益化オフ・埋め込み可・年齢制限なし)。縦でも可(黒帯禁止)。最初の 30 秒が自動再生。最初の 10 秒で実アプリ、80% は実体験。CTA・最上級禁止
- `promo/scripts/verify.sh` が寸法・fps・尺・プロファイル・音声を検査する

## 反映(2026-08-29 実施済み)

| 経路 | 結果 |
|---|---|
| YouTube | `social-1080x1920.mp4` を**限定公開**でアップロード済み(Shorts 扱い): https://www.youtube.com/watch?v=jS5ZW08sCqE 。タイトル/説明は下記テンプレ、子ども向けではない |
| Play の掲載情報 | サービスアカウント `eas-submit@…` に「ストアでの表示の管理」を付与したうえで `npm run store:play -- --video URL` を実行。スマホ用スクショ 7 枚・フィーチャーグラフィック・動画 URL を差し替えて commit(掲載情報の審査に自動送信) |
| App Store Connect | 1.53 が「デベロッパにより却下」(取り下げ)で編集可能だったので、**1.53 の下書き**に `npm run store:asc`(iPhone 6.9 インチ 7 枚・iPad 13 インチ 3 枚)と `npm run store:asc-preview`(App プレビュー、ポスター `00:00:10:10`)を入れた。**審査には出していない**(新しいビルドを添えてユーザーが提出する) |

以前の詰まりどころ(記録): Play は権限が無いと commit が 403 / ASC は審査中のバージョンがあると新バージョンを作れない(409)/ YouTube は OAuth が要るのでブラウザ(claude-in-chrome)で操作した。

手順(再実行するとき):

1. **YouTube**(手動): `promo/out/deliver/social-1080x1920.mp4` を **限定公開**・収益化オフ・埋め込み許可・年齢制限なしでアップロード。
   - タイトル: `まとめくん — 2ch・5chまとめを、読み上げでながら聴き`
   - 説明: `2ch・5chまとめ 60サイト以上を横断して読める「まとめくん」。読み上げ中は画面が自動で追従し、いま読んでいる行がハイライトされます。盛り上がっているスレの検知、日間・週間・月間ランキング、本文だけを読みやすく整形。\n\nApp Store / Google Play で配信中。\nBGM: 甘茶の音楽工房「ハッピータイム」`
   - 「子ども向けではない」を選ぶ。URL(`https://www.youtube.com/watch?v=…`)を控える
2. **Play Console**(手動で権限付与 → コマンド): 上表の権限を付けてから
   `npm run store:play -- --video "https://www.youtube.com/watch?v=XXXX"`(スクショ 7 枚 + フィーチャーグラフィック + 動画 URL を差し替えて掲載情報の審査へ送信。`--dry-run` で確認、`--no-images` で動画だけ)
3. **App Store Connect**(1.53 の審査が終わってから): `npm run store:asc -- --version 1.54`(スクショ iPhone 7 枚 + iPad 3 枚)→ `npm run store:asc-preview -- --version 1.54`(App プレビューを 6.9 インチ枠に上げ、ポスターフレーム `00:00:10:10` を設定)。どちらも下書き 1.54 に入るだけで公開はビルドを添えて提出したとき
4. アップロード前のチェック: 端末フレーム/手/バッジ/URL が App Store 版に無い、「広告」ラベルが映っていない、映った題名が年齢区分と整合、ステータスバー 9:41、`verify OK`
