# ストアスクリーンショット v2（2026-08-28 実施）

v1（2026-08-21、下記）を全面的に作り直した。素材と作り直し方は `store-assets/README.md`、
定義は `scripts/store/slides.mjs`。

## v1 の何が悪かったか

| 不満 | 原因 |
|---|---|
| 上部に黒い淵が残る | `build-store-screenshots.sh` が影マスクを `-roll "+0+N"` で**巡回**させていた。端末を版面外へはみ出させているのでマスクの最下行まで白く、それが最上部へ回り込んで上 18px（Play）/ 26px（iOS）を 42% 暗くしていた（全12枚で実測）。加えて端末フレームが無く、アプリのダークなヘッダー `#212121` がそのまま帯に見えた |
| 画面や文字が小さい | 端末幅が版面の 74%、見出し 84pt を文字数で自動縮小（実測 ~70pt）、サブ 38pt |
| 簡素 | 平坦なグラデ＋端末＋2行の文字だけ |
| 仕様の抜け | iOS が 6.5インチのみで**必須の 6.9インチ（1320×2868）が無い**。`supportsTablet: true` なので **iPad 13インチ（2064×2752）も必須**だが未作成。iOS にも Android の実画面を流用していた |

> ⚠️ ImageMagick の `-roll` は「ずらす」ではなく「巡回」。はみ出したマスクに使うと反対側へ回り込む。
> v2 は合成から ImageMagick を外し、`verify.sh` の上端輝度検査を回帰ガードにしている。

## v2 の骨格と構図

「大きな端末・大きな言葉・1枚1メッセージ」。**骨格は固定、構図は混ぜる**。

- 見出し: M PLUS Rounded 1c Black（アプリ本文と同じ書体）2行・1行 ≤ 8字。Play 104px / iOS 136px / iPad 154px、`#3B2016`
- サブ: 同 Medium 1行 ≤ 22字。Play 48px / iOS 60px / iPad 68px、`#7A4A2E`
- 端末: CSS で描いた黒ベゼル（iPhone は Dynamic Island、Pixel はパンチホール）。幅は版面の 90%、下端は版面外（可視率 71%）
- 拡大チップ: 同じスクショの一部を 1.4〜1.6 倍に拡大して元の位置に重ねる（加工・文字入れなし）
- 背景: CSS グラデ `#FCC3A8`→`#F5824E` ＋ scenario.com で生成した透過の装飾（アイコンを参照画像にして質感を揃えた 3D 吹き出し・音波リング・炎・王冠）。1〜3枚目は装飾を横断させて連続させる
- 構図: A 正面＋チップ（#1 #2 #5 #6）/ B ズームイン（#3）/ C 2台並び（#4 #7）

| # | 型 | 見出し | サブ | 実画面 |
|---|---|---|---|---|
| 1 | A | 読まずに、／聴く。 | 通勤中も作業中も、耳だけでスレを追える | 記事＋読み上げバー（タイトルがハイライト） |

| 4 | C | 今日いちばん／読まれたスレ。 | 日間・週間・月間のランキングと検索 | 検索（後ろ）＋ランキング日間（前） |
| 5 | A | まとめサイトを、／ひとつに。 | 読みたいサイトだけを選んで表示できる | 表示サイトの選択 |
| 6 | A | 読むほど、／好みに寄る。 | あなた向けのおすすめと、記事ごとの関連 | Home「あなたへ」 |

6.5インチは作らない（ASC が 6.9 を流用する）。

## 合成の仕組み（scripts/store/）

HTML/CSS を Playwright（Chromium）で 1:1 レンダリングし、ImageMagick は**アルファ除去と検査だけ**に使う。

- フォント・実画面・装飾はすべて data URL で HTML に埋め込む（`setContent` のページは `file://` を読めない）
- フォントは `node_modules/@expo-google-fonts/m-plus-rounded-1c`（OFL。出力は画像なので再配布義務なし）。
  TTF の cmap を読んで**見出し/サブの全文字が収録されているか**を確認し、無ければ build を落とす（別書体の混入防止）
- build が落ちる条件: 文字領域 > 20%（Play のプロモーション適格条件）/ 画面の可視率 > 75%（タブバー・広告が写る）/ 見出しが版面からはみ出す
- `--debug` で文字・チップ・画面に枠を描き、HTML を `out/debug/` に残す
- Chromium は `--force-color-profile=srgb` で起動する（忘れると背景色がずれる。verify の左上画素検査で検知）

## scenario.com の使い方（scripts/store/gen-props.py）

- `estimate` で `?dryRun=true` の見積もりを出してから `props` を回す。**今回の消費: 装飾 5種 × 23CU = 115CU**（予算 300CU）
- 装飾は GPT Image 2（`model_openai-gpt-image-2`）、`background: transparent`、`referenceImages` にアプリアイコンを渡して質感を揃える。1024²・`quality: auto`・2候補
- 音波リングは参照アイコンの吹き出しが中央に混ざったので、中心を円形マスクで消して採用した（0CU）
- Gemini 3.1 Flash の 4K パノラマ（28CU）も用意してあるが、装飾を CSS で横断配置すれば足りたので使っていない
- 透過になっていない候補は Photoroom（`model_photoroom-background-removal`、3CU）を自動で通す
- パラメータ名は `numOutputs`（v1 の `numSamples` は無効）。`width/height` は 16 の倍数

## 反映と計測

- App Store Connect: 1.53 の審査中はロック。次版で iPhone 7枚＋iPad 3枚を **1枚ずつ、反映を確認しながら**上げる（まとめて上げると並び順が崩れる）
- Play Console: 7枚＋フィーチャーグラフィック。「ストアの掲載情報の実験」で A/B できるが、現状の流入（8件/月）では有意差が出ないので、まずは差し替え前後で「表示回数 → インストール率」を比較する
- レイアウトは「固定」が有利という根拠はない。効くかどうかは A/B で決める。構図 3型はそのための素材

## なぜ作り直したか

現行のスクリーンショットは **2021年のFlutter版**のまま。実測した証拠:

- 記事の日付が `2021-06-22`（東京五輪の話題）
- タブバーが英語（`Ranking / Search / My Page / Setting`）。現行は `79aa8e7` で日本語化済み
- **3枚目に、AdMobから違反と指摘された当のUI（画面下部の「記事を開く」ボタン＋直下の広告）が写っている**
- **同じ3枚目にテスト広告（Test mode）が写り込んでいる**

9/14以降のAdMob審査リクエストでレビュアーの目に触れる可能性がある。
「修正済み」と主張しながら違反時の画面をストアに掲示している状態は避けたい。

## 訴求の方針

**「広告カット」「広告なし」は使わない。** AdMobで収益化していることと矛盾し、
他パブリッシャーの広告を除去していると自ら宣言する形になる
（2026-08-14の違反の引き金。docs/GROWTH-PLAN.md の⚠️を参照）。

代わりに、**競合レビューで実測できた最大の不満に「広告」の語を使わずに答える**
（`docs/COMPETITORS.md`）。Cookie同意ポップアップが閉じられないことと、画像が表示されないことが
競合の二大不満で、まとめくんはどちらも構造的に踏まない。

## デザイン

**アイコンに合わせた明るい暖色**にした。旧計画では「ダークベース＋オレンジの発光」としていたが、
2026-08-21にアイコンをコーラル〜ピーチのグラデーションへ差し替えたため、
ストア面もそちらに寄せないとちぐはぐになる。
アプリ本体はダークテーマなので、明るい背景に置くと実画面が締まって見える利点もある。

| 用途 | 値 |
|---|---|
| 背景グラデーション | `#FCC3A8`（上）→ `#F5824E`（下） |
| 見出し | `#3B2016` / ヒラギノ角ゴ W8 |
| サブ | `#7A4A2E` / ヒラギノ角ゴ W5 |

- 端末は**意図的に画面外へはみ出させている**。バナー広告とタブバーを写さないため
- 見出しは**文字数に応じて自動で縮める**。固定サイズだと長い見出しが画面外へはみ出す
- 日本語は ImageMagick で後乗せ。**生成モデルに日本語を描かせない**

## scenario.com の使い方

`scripts/gen-store-bg.py`。`SCENARIO_API_KEY` / `SCENARIO_API_SECRET` を環境変数から読む。

- モデルは **GPT Image 2**（`model_openai-gpt-image-2`）。プロンプト追従が最も素直だった
- エンドポイントは `POST /v1/generate/custom/{modelId}`。
  `POST /v1/generate/txt2img` は「Standalone models are not supported」で400になる
- **1枚12CU**。7枚で84CU
- 背景と装飾だけを作らせる。文字・UI・端末は一切描かせない（プロンプトで明示的に禁止している）

## 反映手順

1. Play Console → ストアの掲載情報 → スクリーンショット / フィーチャーグラフィックを差し替え
2. App Store Connect → 1.51 のページ → スクリーンショットを差し替え（**セッション切れのため未実施**）
3. アップロード前に確認すること
   - 画面内に広告枠が写っていないか
   - 画面下部にタップ要素が写っていないか
   - 表示中の記事タイトルが年齢区分の申告と整合するか

## 効果測定

Play Console の「ストアのパフォーマンス」で**表示回数→インストール率**を差し替え前後で比較する。
GROWTH-PLAN の目標は新規インストール 8件/月 → 300件/月。
なお**アイコン・説明文・スクリーンショットを同時期に変えている**ので、
個別の寄与は切り分けられない。まとめて「刷新前後」で見る。

# アプリアイコン（2026-08-21 差し替え）

支給されたデザイン（オレンジのグラデーション地に白い吹き出し3つ、大きい吹き出しの中に
書き込みを表す3本の線）を、アプリアイコンとして使える形に整えて差し替えた。

![before / after](assets/icon-before-after.png)

## 支給データに手を入れた点

### 1. 焼き込まれていた角丸と白余白を落とし、全面塗りに直した

支給された 2048px の画像は**角丸が焼き込まれ、外側が白**だった（丸みの半径は実測で約380px）。
このまま入れると iOS/Android がさらにマスクを掛けるので、**二重に丸まって角に白が残る**。

角丸の外側を背景グラデーションで埋めて全面塗りにした。手順:

1. 半径520pxの角丸矩形マスクを作り、外側を「埋める領域」とする
   （実測380pxより大きく取って、元の輪郭のにじみを巻き込まないようにする）
2. 64pxまで落とした画像で「ぼかす → 有効領域だけ元に戻す」を220回繰り返し、
   周囲の色を角へ拡散させる。2048pxのままでは1回あたりの変化量が量子化で消えて拡散が進まない
3. 拡散結果を2048pxへ戻し、境界を50pxぼかしたマスクで元画像と合成する。
   継ぎ目を完全に消すにはこのぼかしが要る

### 2. Android のアダプティブ前景を作り直した

アダプティブアイコンは108dpのうち**中央72dp（66.7%）しか表示されない**。
デザインを70%に縮めて中央に置き、外周は端の画素を伸ばして埋めた（外周は通常見えないが、
ランチャーの視差で覗いたときに違和感が出ないようにするため）。

> ⚠️ `-set option:distort:viewport` に負のオフセットを渡す書き方は効かず、中身が左上へずれた。
> `-distort SRT` で「元画像の中心を出力の中心へ」写す形に変えている。
> **生成後は必ず中心座標を測って確認すること**（ずれるとランチャーで片側だけ切れる）。

### 3. 通知アイコンを彩度で抜き出した

Android のステータスバー通知アイコンは alpha しか見ないため、白いシルエットである必要がある。
このデザインは**白い吹き出し（彩度3%前後）とオレンジの背景（彩度28%以上）**で
はっきり分かれているので、彩度13%で二値化するだけで抜ける。
吹き出しの中の3本の線はオレンジ＝彩度が高いので、**自動的に穴になる**のが都合がよい。

## 実寸で確認した結果

| サイズ / マスク | 結果 |

| iOS 角丸マスク | 全面塗りで、角に白が残らない |
| Android 円マスク | 中央に収まり、どこも切れない |
| Android 角丸マスク | 同上 |
